# Block Cloud Saves
### What's BlockCloudSaves.bat?

**BlockCloudSaves.bat** is an alternative to the NoSave AHK script; and it can be controlled trough the submenu.

**BCS** can be found under the **Settings +** category.

It must be started manually in order to control it through the menu.

### What's the purpose of this tool if it can't be used without YimMenuv2?
<sub><sub>(Actually, it is possible to use this as a standalone tool, it's just not convenient because of how it works)</sub></sub>

The tool itself is pretty much useless if your intention is using it to replay heist finales.
However, if you are testing stuff with YimMenuV2 and don't want your changes to be saved (like edited stats or whatever) you can turn BlockCloudSaves on.

A quick way to start the tool is by clicking the Copy Path button, pressing Win + R on you keyboard and pasting the path to BCS (Accept the UAC prompt so the tool runs as admin).

*This option was initially added as part of an idea I had, but now I think it's just bloat, so I'm considering removing it in the next release.
